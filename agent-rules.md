# Reglas de Agente (SaaS Multi-Tenant de Talleres Automotrices - Quito, Ecuador)

## 1. Competencias Principales
- Experto en Angular (v19+), RxJS, Signals, Tailwind CSS v4, Arquitectura Limpia Frontend y Testing Automático.
- Integración nativa con Supabase (BaaS) usando TypeScript estricto y patrones reactivos.

## 2. Restricciones Estéticas
- Paleta estricta monocromática:
  - Blanco: `#FFFFFF`
  - Negro: `#000000`
  - Gris Neutro: `#E5E7EB` / `#9CA3AF` / `#1F2937` (para bordes, deshabilitados y estados sutiles)
- Estilo visual utilitario, limpio, de alto contraste y tipografía nítida (Mobile-First).
- Sin degradados coloridos ni sombras difusas innecesarias.

## 3. Optimización de Tokens
- Responde únicamente con código estructurado o comandos de terminal.
- Omite saludos, introducciones o explicaciones teóricas de Angular.
